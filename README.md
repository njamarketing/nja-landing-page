# NJA Marketing

Projeto institucional em Next.js com rotas por idioma.

## Estrutura

```text
app/
  [locale]/
    page.tsx
    privacy-policy/
    terms-conditions/
    account-cancellation-policy/
    donations/
components/
  layout/
    Header.tsx
    Footer.tsx
  providers/
    LenisProvider.tsx
i18n/
messages/
utils/
  storeLinks.ts
```

## Desenvolvimento

```bash
npm install
npm run dev
```
